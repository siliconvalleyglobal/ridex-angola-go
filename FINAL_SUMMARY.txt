ARCHITECTURE
------------

The payment provider integration follows these principles:

1. Provider Independence: Core logic doesn't depend on specific providers
2. Interface-Based: All providers implement common interface
3. Factory Pattern: Providers created from configuration
4. Registry Pattern: Providers registered and looked up by name
5. Webhook Verification: All events verified before processing
6. Testability: Each provider tested independently

TECHNICAL DETAILS
-----------------

Provider Interface:
  CreatePaymentIntent(ctx, rideID, amountCents, currency) (*Payment, error)
  GetPaymentStatus(ctx, paymentID) (*Payment, error)
  RefundPayment(ctx, paymentID, amountCents, reason) error
  VerifyWebhookSignature(payload, signature) error
  ParseWebhookEvent(payload, signature) (*WebhookEvent, error)

Webhook Signatures:
  - AppyPay: HMAC-SHA256 with client secret
  - VPOS: HMAC-SHA256 with webhook secret
  - ProxyPay: HMAC-SHA256 with API key
  - Supports hex and base64 encoding
  - Supports "sha256=" prefix

Error Handling:
